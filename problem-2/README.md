Use this [API](https://pokeapi.co/api/v2/pokemon/charmander) to create the screen below:

<img width="239" height="423" alt="image" src="https://github.com/user-attachments/assets/37966eb7-6ff5-4eff-ab87-4e55bc378d1e" />  

The name is in the `name` key of the result  
The image can be found in `sprites.other.home`  
The stats can be found in `stats`  

Sample calls:  
https://pokeapi.co/api/v2/pokemon/bulbasaur  
https://pokeapi.co/api/v2/pokemon/skirtle  
https://pokeapi.co/api/v2/pokemon/pikachu
